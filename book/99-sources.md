# 99 Sources

Each source was read on 2026-11-14. The passage relied on is quoted where the book cites it.
"Abstract" means only the abstract was read. arXiv items are preprints.

- `adams2021` Adams et al., "People systematically overlook subtractive changes", Nature
  592 (2021). doi:10.1038/s41586-021-03380-y. A study of people. Abstract.
- `anthropic2025` Anthropic, "Claude 3.7 Sonnet System Card", section 6.
  <https://www.anthropic.com/claude-3-7-sonnet-system-card>. One model, called infrequent.
- `anthropic-opus48` Anthropic, "Prompting Claude Opus 4.8".
  <https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-4-8>
- `anthropic-prompting` Anthropic, "Prompting best practices". A living page about named models.
  <https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices>
- `claude-memory` Anthropic, Claude Code documentation on CLAUDE.md.
  <https://code.claude.com/docs/en/memory>. No data given.
- `eagle2015` Alex Eagle, "Change-Detector Tests Considered Harmful", Google Testing Blog.
  <https://testing.googleblog.com/2015/01/testing-on-toilet-change-detector-tests.html>
- `ebrahimi2026` Ebrahimi et al., "To Add Is Machine, To Delete Is Human", arXiv 2607.28887.
  About code edits, not instruction files. Abstract.
- `gloaguen2026` Gloaguen et al., "Evaluating AGENTS.md", ICLR 2026 MemAgents workshop,
  arXiv 2602.11988 version 3. Earlier versions claimed more: that such files reduce success.
- `github-linguist` GitHub Docs, "Customizing how changed files appear on GitHub". Read on
  2026-11-15.
  <https://docs.github.com/en/repositories/working-with-files/managing-files/customizing-how-changed-files-appear-on-github>
- `google-review` Google Engineering Practices, "What to look for in a code review". Read on
  2026-11-15. <https://google.github.io/eng-practices/review/reviewer/looking-for.html>
- `google-small-cls` Google Engineering Practices, "Small CLs". Read on 2026-11-15.
  <https://google.github.io/eng-practices/review/developer/small-cls.html>
- `go-mod` Go Modules Reference, section "go mod vendor". Read on 2026-11-15.
  <https://go.dev/ref/mod#go-mod-vendor>
- `house1995` U.S. House Office of the Legislative Counsel, "Manual on Drafting Style" (1995),
  section 102(b)(3). Transcribed from a scanned page.
- `jiang2026a` Jiang et al., "Your Wish Is My Commit: Over-Compliant Refactoring in AI Coding

- `kaplow1992` Louis Kaplow, "Rules Versus Standards: An Economic Analysis", Duke Law Journal
  42, 557. Abstract.
- `konstantinou2024` Konstantinou et al., "Can we find bugs using LLM-generated oracles?",
  arXiv 2410.21136. 24 Java repositories. Also finds these oracles beat a conventional
  generator's. Abstract.
- `kuefler` Erik Kuefler, "Unit Testing", Software Engineering at Google, chapter 12.
  <https://abseil.io/resources/swe-book/html/ch12.html>
- `laban2023` Laban et al., "Are You Sure? ... The FlipFlop Experiment", arXiv 2311.08596.
  2023 models on classification tasks. Abstract.
- `laban2025` Laban et al., "LLMs Get Lost In Multi-Turn Conversation", arXiv 2505.06120.
  Simulated conversations. Abstract.
- `ofr` Office of the Federal Register, "Drafting Legal Documents: Principles of Clear
  Writing". <https://www.archives.gov/federal-register/write/legal-docs/clear-writing.html>
- `openai2025` OpenAI, "GPT-4.1 Prompting Guide". One model family. Archived page.
  <https://developers.openai.com/cookbook/examples/gpt4-1_prompting_guide>
- `rundle2026` Rundle and Waldron, "The Rule of Law", Stanford Encyclopedia of Philosophy,

- `sterken2025` Sterken and Kirkpatrick, "Conversational Alignment with Artificial

  design, so it measures tendency, not frequency. Abstract.
