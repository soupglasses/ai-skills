# Working in this repository

@README.md

- Edit `instructions/`, `skills/`, `book/`, and `decisions/` with the `write-instructions` skill.
- A book claim needs a basis: a source that was read, quoted where cited and listed in
  `book/99-sources.md`, or the mark `Observed`.
- Decisions belong to the maintainer. Change one only when told to.
- When a rule changes, update the "Carried by" line of each decision it implements.
