# Maintainer decisions

What the maintainer wants done. Living records: rewrite a file when its decision changes,
delete it when it no longer holds. Numbers are not reused.

Each file gives the **Decision**, the **Why** (so it can be applied to unnamed cases, with
"not recorded" where none was given), and **Carried by**: the rules that implement it, which
change in the same edit. Only the maintainer changes a decision.
