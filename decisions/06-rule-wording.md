# 06 Rules are rewritten, not patched

Decided 2026-11-14.

**Decision.** A rule that causes the wrong behaviour is replaced by a rule worded for the
behaviour wanted, not extended with exceptions. Each word is chosen for the action it causes.
How laws are drafted is used as a guide.

**Why.** Agents add rather than rewrite, so a fixed rule becomes "A, but not X, Y, or Z"
where a new rule B would say what is wanted. Small words matter: "describe the failure" led
to paragraphs and a stop, while "note the failure" led to a sentence and continued work.
