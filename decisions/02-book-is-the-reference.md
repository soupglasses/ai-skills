# 02 The book is the reference for the rules

Decided 2026-11-14.

**Decision.** The book lists the ways agent work goes wrong, in numbered chapters. The
instructions and skills are written from it, and a review checks an agent's work against it.
A claim in the book cites only a source that was read, for something that source says.

**Why.** One reference lets the same failures guide both writing the rules and checking the
work. A link to a source that does not say the claim gives false confidence.

**Carried by.** `book/README.md`, `CLAUDE.md`, `skills/write-instructions`,
`skills/check-behaviour`.
